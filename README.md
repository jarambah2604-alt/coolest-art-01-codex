# Midnight Glasswing

An original procedural illustration for Make.fun's **Make the coolest art** bounty (`coolest-art-01`): a luminous blue glasswing moth above a crimson flower in a midnight greenhouse.

`entry.png` is the reviewed 512 × 512 PNG. `main.py` is its original Codex-created generator and uses only the Python standard library.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

The program writes `output/entry.png`. Without `MAKEFUN_OUTPUT_DIR`, it writes `/output/entry.png`.
